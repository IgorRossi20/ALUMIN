# ALUMIN - Website Institucional

## Sobre o Projeto
Website institucional desenvolvido para a ALUMIN, empresa especializada em esquadrias de alumínio de alta qualidade. O site apresenta os produtos e serviços da empresa, incluindo portas, janelas e guarda-corpos, com um design moderno e responsivo.

## Funcionalidades
- Navegação intuitiva com menu responsivo
- Galeria de projetos com filtros por categoria
- Modal interativo para visualização detalhada dos projetos
- Carrossel de imagens com controles de navegação
- Formulário de contato integrado
- Botão flutuante de WhatsApp para contato rápido
- Design totalmente responsivo para todos os dispositivos

## Tecnologias Utilizadas
- HTML5
- CSS3 (com variáveis CSS e animações)
- JavaScript (Vanilla)
- AOS (Animate On Scroll) para animações
- Google Maps API para integração de mapas

## Como Executar
1. Clone o repositório:
```bash
git clone https://github.com/IgorRossi20/alumin-esquadrias-website.git
```
2. Abra o arquivo `index.html` em seu navegador

## Estrutura do Projeto
```
├── index.html           # Página inicial
├── projetos.html        # Página de projetos e galeria
├── sobre.html           # Página sobre a empresa
├── styles-new.css       # Estilos do site
├── script-new.js        # Scripts de funcionalidade
└── PHOTOS/             # Diretório de imagens
```
